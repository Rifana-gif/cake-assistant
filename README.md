# AI-Based Personalized Cake Recommendation System with Design Assistance

Pipeline: User Input -> Data Processing -> Cosine Similarity Recommendation -> Design Suggestion -> Final Output (Streamlit UI)

## Files
- app.py : full Streamlit app
- cake_data.csv : sample cake dataset (120 rows)
- requirements.txt : libraries

## Run locally
pip install -r requirements.txt
streamlit run app.py
